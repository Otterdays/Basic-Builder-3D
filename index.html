What’s new

    Shortcuts & tools

    • 1–9, 0 — select piece (0 = spray)
    • M — cycle material · G — grid · H — paint both grounds · B — collapse / expand tools panel
    • Panel edge — drag to resize · double-click resizer to reset width
    • U — grassy yard (grass site + dusk lighting)
    • R / Q — rotate ghost ±90° · X Y Z — rotation axis
    • Fence post / rail / panel — toolbar; ] cycle · N next post (+2 m) · snaps to posts
    • Ctrl+Z / Ctrl+Y — undo / redo
    • T — measure (click A & B) · P — repeat last at ghost · C — clone hovered part
    • V — toggle plan (ortho) view · L — cycle lighting
    • V — plan view (orthographic top) · F — frame all · Home — reset camera
    • Del / Backspace — remove part under cursor (build mode)
    • ` (backtick) — FPS & part count overlay · hold Alt — ¼ m grid snap
    • Esc — exit walk, close help, or turn off measure
    • What’s new — toolbar button; Esc closes dialogs (update modal first).
    • ? — this help · blueprint auto‑saves a browser draft while you build
    • Build level — new parts are tagged; filter visibility with “Show only this level”.
