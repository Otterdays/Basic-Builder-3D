# My Thoughts

## 2026-04-23
- Initializing project. Choosing Three.js for the 3D engine as it's the industry standard for web-based 3D.
- Will use a modular approach in JS despite being "vanilla" to keep code manageable.
- Focus on "premium" look: Bloom effects, soft shadows, and glassmorphism UI.

## 2026-04-23 (v0.3.0)
- Expanded material library to include industrial and outdoor options.
- Implemented simulated materials for Grass, Asphalt, and Glass to provide immediate variety without heavy asset loads.
- Refined the grid-snapping algorithm to dynamically handle variable item heights, which is crucial for stacking complex items like pipes and pots.
- Shifted to a more robust "Standard Material" configuration in Three.js to ensure visual consistency across textured and non-textured objects.
